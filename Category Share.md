# Общие категории каналов (Category Share)

Плагин для Стройчат, который позволяет **делиться категорией сайдбара по ссылке**: пользователь открывает ссылку, видит список каналов и может применить категорию к своему сайдбару.

## Идея

- Автор выбирает категорию в сайдбаре и генерирует **share-ссылку**.
- Получатель открывает ссылку и подтверждает действие.
- Плагин:
  - добавляет пользователя в указанные **публичные** каналы (если он ещё не участник);
  - создаёт (или обновляет) **кастомную категорию** в сайдбаре пользователя и добавляет туда эти каналы.

## Ограничения и правила доступа

- Ссылка **работает только для участников команды** (team membership проверяется и при предпросмотре, и при применении).
- При создании ссылки поддерживаются **только публичные каналы** (private/DM/GM не допускаются).
- Список каналов в ссылке фиксируется на момент создания. При применении плагин повторно валидирует каналы и пропускает те, что больше не подходят.

## Сборка

```bash
make dist
# Архив: dist/com.company.category-share.tar.gz
```

## Установка

- Загрузить архив через **System Console → Plugins** (Upload Plugin).
- Или положить архив в `server/prepackaged_plugins/` (для сборок с prepackaged plugins).

## Технические детали (для разработчиков)

- **Plugin ID**: `com.company.category-share`
- **API**:
  - `POST /plugins/com.company.category-share/api/v1/share-links` — создать ссылку
  - `GET /plugins/com.company.category-share/api/v1/share-links/{token}` — предпросмотр
  - `POST /plugins/com.company.category-share/api/v1/share-links/{token}/apply` — применить
- Токены и полезная нагрузка хранятся в **KV store** сервера.
