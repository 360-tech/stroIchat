# СтройБезопасность (Safety & Compliance)

Плагин для Стройчат: фиксация нарушений по охране труда, задачи прорабам субподрядчиков, эскалация при просрочке.

## Идея

- **ИТР** (прораб, мастер, специалист по ОТ) фиксирует нарушение из канала → бот публикует карточку нарушения в этом же канале и ставит задачу **прорабу субподрядчика** в ЛС.
- У прораба по умолчанию **24 часа** на устранение и отчёт (значение можно изменить в настройках плагина).
- Если не отреагировал — **#эскалация**: уведомление тому, кто создал нарушение (руководитель/генподрядчик).
- Субподрядчик разбирается со своими нарушениями; генподрядчик контролирует их ИТР; прозрачная история для претензий и штрафов.

## Команды (рус.)

- **/нарушение** — открыть форму создания нарушения (выбор дедлайна пресетами или «свой»).
- **/нарушение** описание @ответственный — откроет форму с предзаполненными полями.
- (опционально) **/нарушение** описание @ответственный дд.мм.гггг чч:мм — откроет форму и подставит «Свой дедлайн».
- **/отчет** — мои задачи.
- **/отчет** @пользователь — открытые нарушения по этому пользователю.
- **/отчет все** — все открытые нарушения.
- **/отчет эскалации** — список эскалированных нарушений.
- **/охрана** — инструкция по использованию бота.
- **/исправлено** — отметить нарушение как исправленное в треде с карточкой нарушения.

Ответственный отчитывается в канале: находит тред с карточкой нарушения и выполняет команду **/исправлено** в этом треде (**с фото или без** — фото можно прикрепить отдельным сообщением).

После этого бот:

- пишет сообщение об исправлении **в треде карточки** (история по нарушению)
- дополнительно публикует короткую отметку **в ленте канала** (top-level) со ссылкой на карточку
- отправляет уведомление создателю нарушения (если создатель не совпадает с ответственным)

### Вложения (фото/файлы)

- Вложения прикрепляйте **отдельным сообщением в треде** карточки нарушения (в канале).
- Так можно добавлять фото/файлы после создания нарушения (например, доказательство устранения).

Алиасы: `/violation`, `/report` работают так же.

## Требования

- БД и (опционально) S3 — из настроек сервера (Environment). Отдельная настройка плагина не нужна.

## Установка

```bash
make dist
# Архив: dist/com.company.safety-compliance-*.tar.gz
```

Загрузить через System Console → Плагины или положить в `server/prepackaged_plugins/`.

## Схема БД

Плагин создаёт таблицы: `mm_users`, `violations` (с полями deadline_at, escalated_at, escalated_to_mm_id), `evidence`, `permits`.
