# Стройчат мессенджер

## Доступ к dev-серверу в локальной сети

1. Отредактируйте `server/config.override.mk`: по умолчанию `LAN_PORT=8065`, поэтому `make run` продолжает работать на `http://localhost:8065`. Чтобы открыть отдельный порт (например, `3113`), измените `LAN_PORT`.
2. Make автоматически экспортирует `MM_SERVICESETTINGS_LISTENADDRESS=0.0.0.0:<LAN_PORT>`, поэтому Mattermost слушает все интерфейсы — заходите и по `http://localhost:<LAN_PORT>`, и по `http://<LAN_IP>:<LAN_PORT>` с другой машины.
3. Если нужно жёстко задать публичный адрес (например, для обратных ссылок в письмах), укажите `LAN_SITEURL=http://<LAN_IP>:<LAN_PORT>`. По умолчанию `MM_SERVICESETTINGS_SITEURL` не переопределяется, и оба адреса работают одновременно.
4. Запустите `make run` в директории `server` и разрешите входящие подключения к выбранному порту в фаерволе.
