# Стройчат 🏗️💬

`Стройчат` — корпоративный мессенджер для строительной отрасли. Он помогает командам, подрядчикам, партнерам и внешним участникам работать в едином пространстве общения: обсуждать задачи, согласовывать решения, обмениваться файлами и поддерживать прозрачную коммуникацию по проектам.

Проект является форком `Mattermost`, адаптированным под сценарии рабочих коммуникаций в строительной и проектной среде.

## Что умеет приложение ✨

`Стройчат` поддерживает несколько форматов общения:

- `#` каналы для команд, объектов, подразделений и проектных потоков;
- `💬` личные чаты для прямой коммуникации между участниками;
- `👥` групповые чаты для небольших рабочих обсуждений;
- `🔒` приватные каналы для закрытых тем и ограниченного состава участников;
- `🧵` треды для ведения обсуждений внутри конкретного сообщения без засорения основного потока.

Для повседневной работы в приложении также доступны:

- `🔎` поиск по сообщениям и файлам;
- `@` упоминания пользователей и служебные упоминания;
- `⚡` автодополнение при наборе пользователей и каналов;
- `📎` загрузка и обмен файлами;
- `⌨️` индикатор набора текста в реальном времени;
- `🧵` отдельный сценарий работы с тредами и непрочитанными ответами.

В кодовой базе также присутствует поддержка общих каналов между подключенными рабочими пространствами, что позволяет выстраивать коммуникацию между разными контурами и командами, если такой режим включен в конфигурации.

## Доступ для партнеров 🤝

В проекте реализован отдельный ограниченный тип доступа для внешних участников — `partner`. По смыслу это близко к гостевому режиму: таких пользователей можно приглашать в систему с ограничением доступа только к выбранным командам и каналам.

Это позволяет безопасно подключать к обсуждениям:

- `🏢` заказчиков;
- `🦺` подрядчиков;
- `🚚` поставщиков;
- `📐` проектные и согласующие стороны;
- `🧠` внешних консультантов.

Такой режим удобен, когда нужно дать доступ к конкретным рабочим веткам без открытия всей внутренней структуры компании.

## PWA и мобильный доступ 📱

`Стройчат` поддерживает сценарий работы как `PWA`-приложение.

Это дает следующие преимущества:

- `📲` более нативный мобильный сценарий использования;
- `🧩` возможность использовать веб-клиент как установленное приложение;
- `🔔` отображение бейджа непрочитанных сообщений в поддерживаемых окружениях.

## Боты, интеграции и автоматизация 🤖

В проекте используются внутренние предустановленные плагины(боты):

- `🔗 Category Share` (`com.company.category-share`) — описание: [Category Share](Category%20Share.md). Позволяет делиться пользовательскими категориями каналов. В интерфейсе можно сформировать ссылку на категорию, выбрать публичные каналы, которые войдут в подборку, и отправить эту ссылку другому пользователю. Получатель может открыть предпросмотр, присоединиться к каналам из ссылки и создать у себя такую же категорию в боковой панели.
- `🛡️ Safety Compliance` (`com.company.safety-compliance`) — описание: [Safety & Compliance](Safety%20%26%20Compliance.md). Входит в набор внутренних plugin bundle, которые собираются вместе с серверной поставкой и добавляются в `prepackaged_plugins`. Этот плагин предназначен для внутренних сценариев, связанных с безопасностью и compliance-практиками корпоративного контура.

## Для чего подходит Стройчат 🎯

`Стройчат` можно использовать как единый контур коммуникации для:

- `🏢` внутренних обсуждений команд;
- `🏗️` координации по объектам и проектам;
- `🚧` взаимодействия между офисом и площадкой;
- `🤝` подключения внешних партнеров в ограниченном режиме;
